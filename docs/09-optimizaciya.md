# Урок 9. Оптимизация скорости локального DeepSeek

[← Урок 8](08-promptting.md) · [Оглавление](../README.md) · [Урок 10 →](10-rag-i-agenty.md)

## Две скорости, которые нужно различать

- **Prefill / prompt processing (pp)** — сколько токенов промпта в секунду «читает» модель. Важно для длинных документов. Упирается в вычисления GPU.
- **Generation / token generation (tg)** — сколько токенов в секунду пишет. Упирается в **пропускную способность памяти**.

Отсюда: Mac с огромной памятью быстро генерирует, но медленнее «читает» длинные промпты, чем топовая NVIDIA.

## Чек-лист ускорения (по убыванию эффекта)

1. **Вся модель на GPU.** Даже 10% слоёв в RAM может замедлить генерацию в разы.
2. **Меньше квант** (Q4 вместо Q8) → почти линейный рост скорости генерации.
3. **Для MoE — эксперты в RAM, остальное на GPU** (`-ot ".ffn_.*_exps.=CPU"`). Быстрее, чем «N слоёв целиком».
4. **Flash-attention** (`-fa on` / `OLLAMA_FLASH_ATTENTION=1`).
5. **Квантованный KV-кэш** `q8_0` — освобождает VRAM под слои.
6. **Спекулятивное декодирование** — драфтер (DSpark для V4-Flash) или маленькая модель того же семейства. 1.5–2× на генерации.
7. **Правильные потоки:** `-t` = число физических ядер; на гибридных Intel — только P-ядра.
8. **Больше батч префилла:** `-b 2048 -ub 2048` ускоряет обработку длинных промптов (нужна память).
9. **Кэш промпта:** llama-server и vLLM переиспользуют общий префикс — держи системный промпт неизменным.
10. **Двухканальная/многоканальная память** — для CPU-инференса критична скорость RAM (DDR5, все каналы заняты).

## Оценка «потолка» скорости генерации

```
ток/с ≈ Пропускная способность памяти (ГБ/с) / Объём активных весов на токен (ГБ)
```

Пример: RTX 4090 (~1000 ГБ/с), 14B в Q4 (~9 ГБ) → теоретически ~110 ток/с, на практике 60–80.
Для MoE считаются только **активные** параметры: V4-Flash (13B активных, ~3.5 бита) ≈ 6 ГБ на токен — поэтому даже в RAM генерация остаётся приемлемой.

## Профилирование

```bash
# llama.cpp
./build/bin/llama-bench -m model.gguf -ngl 99 -fa 1 -p 2048 -n 256

# Ollama: статистика после ответа
ollama run deepseek-r1:8b --verbose
```

`--verbose` покажет `prompt eval rate` и `eval rate` (ток/с).

## Тюнинг для Mac

```bash
# Разрешить GPU использовать больше единой памяти (пример для 128 ГБ → 120 ГБ)
sudo sysctl iogpu.wired_limit_mb=122880
```

Сбрасывается после перезагрузки. Оставь системе 8–16 ГБ.

## Тюнинг для Linux + NVIDIA

- Режим максимальной производительности: `sudo nvidia-smi -pm 1`
- Несколько GPU: `CUDA_VISIBLE_DEVICES=0,1`, в llama.cpp — `--split-mode layer` (по умолчанию) или `row`
- Большие страницы и NUMA на серверах: `--numa distribute`
